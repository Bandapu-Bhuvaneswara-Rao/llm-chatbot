🤖 LLM Chatbot
____________________
A full-stack AI chatbot application built using React.js, Node.js, Express.js, and Ollama/TinyLlama.

The chatbot generates intelligent responses through a locally running Large Language Model (LLM) with a modern responsive UI.

🚀 Tech Stack
_______________________

React.js

Node.js

Express.js

Ollama

TinyLlama

Axios

REST APIs
✨ Features
_______________________
Real-time AI responses

Full-stack architecture

Local LLM integration

Responsive chatbot UI

REST API communication
